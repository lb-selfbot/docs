# With UI

Upon downloading the latest version of LightningBot, follow these steps to install it on macOS:

1. Open the `ui.dmg` file.

2. Drag the LightningBot icon into the `Applications` folder.

3. You can now start LightningBot from your Applications folder or by using the macOS search bar. Once you start LightningBot, you'll encounter a login screen.

Now that you have successfully installed LightningBot, you can proceed to the [Setting Up](/setting-up/ui) page for further setup instructions.
