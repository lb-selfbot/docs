# Game Commands

Game commands are a collection of commands that are related to games. You can use these commands to get information about games: there are currently Minecraft, Fortnite, Apex Legends and GTA V/FiveM commands.

:::tip
Would you like to see support for a certain game? You can always leave a suggestion in our [Discord server](https://lightning-bot.com/discord)!
:::
