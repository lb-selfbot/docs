# Backup Commands

Backup commands can be used to backup your Discord account. You can store multiple backups at once by using the backup name argument.

:::info
Backup files are stored in `LightningBot/Backups`.
:::

:::danger
Using backup commands requires your Discord account to be phone verified.
:::
