# Protection Commands

Protection commands can be used to protect your account and servers from malicious users.

## Account Protections

- With `[p]antiphising`, you can enable anti-phishing protection for your account. This will notify you when a user sends a messsage with a known phising link.
- With `[p]antifriendrequest`, you can block friend requests from unknown users when you are being spammed with friend requests.
- With `[p]antimassdm`, you can block Direct Messages from unknown users when you are being spammed with DMs.

## Server Protections

- With `[p]antiinvite`, you can block users from sending invite links in your server.
- With `[p]antispam`, you can block users from spamming messages in your server.
- With `[p]antiupper`, you can block users from sending messages with too many uppercase letters in your server.
- With `[p]antidelete`, you can get notified when a user deletes a message in your server.
