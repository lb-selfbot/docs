# Sharing Commands

Sharing commands can be used to share LightningBot commands with other users. You must specify both the user(s) who you want to share with and the command(s) you want to share. You can also select whole categories to share.

:::danger
Sharing commands can be dangerous. Users that you share commands with, depending on which commands you share, will be able to use dangerous commands like `shutdownpc` and `deleteserver`. Only share commands with users that you trust and don't share commands that can potentially be dangerous. You should only use `shareall` if you are sure that you want to share all of your commands with another user.
:::
