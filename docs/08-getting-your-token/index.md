# Getting Your Token

There are three main methods to obtain your token for LightningBot:

- **Browser Developer Tools**: You can use this method to obtain your token from the Discord web app without having to install anything. This method will be explained in the [next page](/getting-your-token/developer-tools).

- **Login with a web browser**: You can use this method to obtain your token by logging into Discord with a web browser. This method will be explained in the [Setting Up](/category/setting-up) page.

- **Login with a saved account**: You can use this method to obtain your token by using a saved account from the Discord app. This method will be explained in the [Setting Up](/category/setting-up) page.
