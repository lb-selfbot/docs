# With UI

After downloading the latest version of LightningBot, you can start the installation by opening the `ui.dmg` file. Now drag the LightningBot icon to the `Applications` folder. You can now start LightningBot from your Applications folder or by searching for it in the macOS search bar. After starting LightningBot, you will see a login screen. Continue to the [Setting Up](/category/setting-up) page to set up LightningBot.
