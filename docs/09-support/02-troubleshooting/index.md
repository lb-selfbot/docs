# Troubleshooting

## Known Issues

- **LightningBot can't be opened because Apple cannot check it for malicious software.**  
  This is a known issue with macOS. To fix this, open the `System Preferences` app, go to `Security & Privacy`, and click `Open Anyway` next to the message about LightningBot being blocked.

## General Troubleshooting

If you are experiencing issues with LightningBot, reinstalling it may fix the issue. To do this, follow these steps:

1. Find the location of the LightningBot folder. You can find the specific folder in the FAQ: [Where does LightningBot store data?](/support/faq#where-does-lightningbot-store-data)

2. Delete the `LightningBot` folder. This will clear all of your configuration settings and other data.

3. Restart LightningBot. You should enter the setup process again. Go to the [Setting Up](/category/setting-up) section for further instructions.
