# Sessions Commands

Sessions commands can be used to view the sessions on your Discord account.

## Gateway Sessions

Gateway sessions are a list of clients that are currently connected to Discord using your account: they are connected to the Discord "gateway".

## Login Sessions

Login sessions are a list of all logged in clients. This includes Discord clients that are logged into your account, but are not currently online.
